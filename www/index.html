指南

安装、使用、数据来源，一页看懂

01这个 App 是做什么的

医疗器械的法规和政策更新得快，文件分散在政府网、药监局等多个网站上。MedReg Radar 把它们收拢到一处，按 影像设备 / 医疗器械 / 背景 分级，配上图表，并能一键导出给你常用的 AI。每条都附官方原文链接。

  • 动态：最新文件列表，可按时间、分级、关键词筛选，并一键导出给你的 AI。
  • 雷达：每个点是一份新文件，越靠中心越和影像设备相关。
  • 数据：历年趋势、每月注册数等图表，每张都能切换成表格。
02装到手机桌面

iPhone / iPad（要用 Safari 打开）

  1. 用 Safari 打开本页。
  2. 点底部中间的“分享”按钮（方框加向上的箭头）。
  3. 往下滑，点“添加到主屏幕”，再点“添加”。

安卓手机

  1. 用 Chrome 或系统浏览器打开本页。
  2. 点右上角“⋮”菜单，选“安装应用”或“添加到主屏幕”。
  3. 也可以直接安装安卓安装包（.apk），见下一条。
03安卓安装包（.apk）
  1. 在项目的 GitHub 页面点 Releases，下载最新的 .apk 文件。
  2. 打开下载好的文件。系统提示“禁止安装未知来源应用”时，点“设置”，允许这个浏览器或文件管理器安装，再返回点“安装”。
  3. 小米 / 红米手机可能提示“安全守护”或要求扫描，选择“继续安装”。

安装包和网页版内容完全相同，数据都来自同一个地方，打开时自动更新。

04装到电脑
  1. 用 Chrome 或 Edge 打开本页。
  2. 地址栏最右边有一个“安装”小图标（电脑加向下箭头），点它，再点“安装”。
  3. 之后可以像普通软件一样从桌面或启动台打开。
05把数据交给你的 AI 分析

本 App 不内置 AI，也不需要任何 key。你可以把筛选出的文件一键交给自己常用的 AI。

  1. 在“动态”页筛选你关心的范围，比如“近 90 天 + 影像设备”。
  2. 在“想让 AI 做什么”里选一个任务，比如“对医院设备科工程师有什么影响”。
  3. 点“复制给 AI”，打开豆包、DeepSeek、Kimi 等聊天 App，粘贴、发送。手机上也可以点“分享到 App”直接发过去。
  4. 想用 Excel 整理，点“下载 .csv”；想上传文件给 AI，点“下载 .md”。

导出的内容自带说明，要求 AI 只根据资料回答、标注编号、不编造。重要结论请点原文核对。

给智能体：完整数据公开在雷达网页的 data.json，可以让你的智能体直接读取。

06数据从哪来，多久更新
  • 中国政府网·政策文件库：每周一自动抓取。
  • 国家药监局：该网站不允许程序访问，由维护者在浏览器中正常保存页面后导入，不做任何绕过。

所有设备读取同一份数据：打开 App 时自动检查更新，有新数据会在底部提示。没有网络时显示上次的内容，顶部会标“离线缓存”。

07常见问题
  • 打不开或一直转圈：数据托管在 GitHub，部分网络下访问较慢。可以换手机流量试试；App 会先显示离线内容。
  • AI 回答不准：导出的资料只包含标题、日期和摘要片段，深入问题请让 AI 结合原文链接，或交给能联网的智能体。
  • 分级不准：分级由关键词规则生成，可能有误，一切以原文为准。
