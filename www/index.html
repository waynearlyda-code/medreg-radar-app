指南

安装、使用、数据来源，一页看懂

01这个 App 是做什么的

医疗器械的法规和政策更新得快，文件分散在政府网、药监局等多个网站上。MedReg Radar 把它们收拢到一处，按 影像设备 / 医疗器械 / 背景 分级，配上 AI 解读和问答。每条都附官方原文链接。

  • 动态：最新文件列表，可按时间、分级、关键词筛选。
  • 雷达：每个点是一份新文件，越靠中心越和影像设备相关。
  • 数据：历年趋势、每月注册数等图表，每张都能切换成表格。
  • 问 AI：针对收录的文件提问，回答标注出处。
02装到手机桌面

iPhone / iPad（要用 Safari 打开）

  1. 用 Safari 打开本页。
  2. 点底部中间的“分享”按钮（方框加向上的箭头）。
  3. 往下滑，点“添加到主屏幕”，再点“添加”。

安卓手机

  1. 用 Chrome 或系统浏览器打开本页。
  2. 点右上角“⋮”菜单，选“安装应用”或“添加到主屏幕”。
  3. 也可以直接安装安卓安装包（.apk），见下一条。
03安卓安装包（.apk）
  1. 在项目的 GitHub 页面点 Releases，下载最新的 .apk 文件。
  2. 打开下载好的文件。系统提示“禁止安装未知来源应用”时，点“设置”，允许这个浏览器或文件管理器安装，再返回点“安装”。
  3. 小米 / 红米手机可能提示“安全守护”或要求扫描，选择“继续安装”。

安装包和网页版内容完全相同，数据都来自同一个地方，打开时自动更新。

04装到电脑
  1. 用 Chrome 或 Edge 打开本页。
  2. 地址栏最右边有一个“安装”小图标（电脑加向下箭头），点它，再点“安装”。
  3. 之后可以像普通软件一样从桌面或启动台打开。
05使用“问 AI”：申请自己的 key

问答用的是 DeepSeek 大模型，按用量从你自己的账户扣费，单次问答用量很小。

  1. 打开 platform.deepseek.com，注册并登录。
  2. 左侧点“充值”，少量充值即可。
  3. 左侧点“API keys” → “创建 API key”，复制以 sk- 开头的那串字符。
  4. 回到 App，点“问 AI”，粘贴并保存。

安全说明：key 只保存在你这台设备上，直接发给 DeepSeek，不经过任何其他服务器。换手机或清除浏览器数据后需要重新填写。建议在 DeepSeek 后台设置消费上限；在公用设备上用完点“清除 key”。

06数据从哪来，多久更新
  • 中国政府网·政策文件库：每周一自动抓取。
  • 国家药监局：该网站不允许程序访问，由维护者在浏览器中正常保存页面后导入，不做任何绕过。

所有设备读取同一份数据：打开 App 时自动检查更新，有新数据会在底部提示。没有网络时显示上次的内容，顶部会标“离线缓存”。

07常见问题
  • 打不开或一直转圈：数据托管在 GitHub，部分网络下访问较慢。可以换手机流量试试；App 会先显示离线内容。
  • AI 说“资料里没有”：它只根据本站收录的文件回答，这是为了不编造。
  • 分级不准：分级由关键词规则生成，可能有误，一切以原文为准。
  • 声明：本 App 由程序从公开渠道整理，非官方发布，不提供法律或合规意见。
